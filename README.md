# EMA Alert Indicator (TradingView / Pine Script v5)

A TradingView indicator built and delivered as a client project. The source code belongs to the client and is **not published** here. This page describes the work only.

## What was built
- A multi-timeframe alert indicator: a higher-timeframe trend filter combined with a lower-timeframe confirmation
- Moving averages shown on the chart, switched automatically by timeframe
- Real-time alerts, an ON/OFF switch for signals, and a debug display for checking conditions

## My role
- Turned the client's written specification into Pine Script v5
- Grouped the settings so the client can adjust them
- Checked behavior on the chart with the debug display before delivery
